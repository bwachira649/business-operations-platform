# Security Policy

## Supported Versions

OpsFlow is currently a portfolio and development project. Security fixes should be reported against the latest version of the repository.

## Reporting a Vulnerability

Please do not publicly disclose a security vulnerability before it has been reviewed.

Report security concerns privately through the repository's available GitHub security/contact mechanisms.

Include:

- A clear description of the vulnerability
- Steps to reproduce it
- Potential impact
- Any relevant logs or screenshots
- A suggested mitigation, if known

Do not include real passwords, API keys, access tokens, personal credentials, or other sensitive information in reports.

## Development Security

OpsFlow is not represented as production-hardened. A production deployment would require additional controls such as authentication, authorization/RBAC, secure secret management, TLS, rate limiting, hardened database configuration, audit logging, backups, monitoring, and dependency/security management.
